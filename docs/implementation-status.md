|---|---|---|

| Phoenix Dataset | 완료 · 실서버 확인 필요 | Fixture 및 공개 REST 어댑터, 버전·예제·프로젝트 span 조회, 원본과 공통 필드 보관, 중복·누락 표시, 불변 Dataset 편집 |

| P2 | 미구현 | 별도 협의 대상으로 지정된 Jenkins 게이트와 예약 반복 실험 |

## 동작 범위

- Mock HTTP는 단일 텍스트 정책 질문을 지원합니다. 파일·이미지·테이블은 JSON 메타데이터로 보존·표시합니다. 바이너리 업로드, 실제 미디어 채널 호출, 사내 멀티턴 세션 리플레이는 별도 어댑터가 필요합니다.
- 합성 환경에서 DeepEval Tool Correctness, Ragas Exact Match, 선언형 규칙이 외부 인증 없이 동작합니다. Judge 기반 지표의 실모델 품질이나 호출 비용은 측정하지 않았습니다. Judge 미설정 상태는 UI에 표시됩니다.
- 가져오기는 한 트랜잭션으로 처리하고 진행 중 표시와 완료 수를 제공합니다. 실시간 항목별 진행률과 대용량 Trace의 서버 측 검색·페이지네이션은 추가 작업입니다. 현재 케이스 목록은 버전 단위로 받아 브라우저에서 페이지를 나눕니다.
- 지표 실행은 워커당 한 케이스씩 처리합니다. 모델 호출의 제한 시간·재시도 설정과 워커 복구가 있습니다. 지표별 독립 동시성 풀과 비용 공급자별 정산은 미구현입니다.
- 비교 화면은 지표별 점수차로 판정합니다. 별도의 Pairwise Judge와 온라인 트래픽 분기는 구현하지 않았습니다.
- 실제 PRD 호출은 차단합니다. 배포를 위한 안전 계약 확인 전에는 실험 이름이나 클라이언트 옵션으로 이 정책을 해제할 수 없습니다.
