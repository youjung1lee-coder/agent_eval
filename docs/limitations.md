# Limits and honest verification boundaries

- Real GAIA layout, config, A2A and credentials are unknown. `eval_agent.json` is a PoC contract, not a claimed company standard.
- Actual LangGraph and official LangFlow LFX JSON execute locally. LFX's serializer/private raw-edge workaround is isolated to the sample builder; runtime output mapping is adapter-only. Other LangFlow versions must run adapter contract tests.
- Sample answer generation, knowledge corpus, lexical local search and business tools are deterministic mocks. No real S3/OpenSearch/Milvus/MyAccess/Jenkins/auth/enterprise infrastructure is configured. Retrieval IDs and ground-truth references are real to the mock corpus.
- Custom LLM judges use actual Qwen 0.5B CPU inference with constrained JSON; a production judge must be calibrated and evaluated for language, rubric compliance and prompt injection. Structured syntax does not ensure a correct judgment. Model weights are pinned/downloaded with SHA256; excluded from Git.
- Normalized operational observation is exported as root attributes and queried from actual Phoenix. External GAIA traces need a root/child attribute mapper. Missing observations are not evidence of success or invented failure. Phoenix ingestion is asynchronous; generation consumes currently available spans, up to 1000 per query.
- Definition probes are owner-supplied integration metadata. Workflow discovery alone does not manufacture business input/expected answers. Unprobed inventory is uncovered. Coverage is design coverage, not successful runtime coverage.
- Production query coverage is bounded observed-window coverage; future usage is unknown. Exact normalized scenario IDs/variations are preserved, but semantic clustering and automatic minimum test-set optimization are deferred.
- Case runtime is single-turn, in-process trusted code. Timeout sample uses a bounded delay and explicit deadline simulation; arbitrary Python hard timeouts/process isolation are not provided. A hung third-party agent can block a local run. Distributed queues, cancellation and multi-turn/streaming require runner extensions.
- Registration executes trusted Python/Flow component code and local absolute paths. Server binds loopback with same-origin guard, but is not an enterprise multiuser/RBAC service. Audit owner is local placeholder. Do not expose this PoC to untrusted networks or upload untrusted agent repositories.
- Golden snapshots freeze cases/bindings/custom definitions; current source changes require re-registration. Results record platform evaluator version, dependency versions and model hash. Exact historical reproduction also needs archived agent code, runtime, connector data and model, not just dataset metadata.
- Platform deployment status is PASS/HOLD only. Jenkins and deploy side effects are absent. Impact filtering supports explicit dependency IDs; automatic diff/impact inference and coordinated multi-agent rollout are deferred.
- Code-based evaluator extension is trusted developer registry registration only, without UI arbitrary-code execution. Full plugin distribution/approval/sandboxing is deferred.
